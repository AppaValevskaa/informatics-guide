# Информатика для первокурсника: системы счисления

**Автор:** Студент Полина

**Тема:** системы счисления

**Цель:** объяснить первокурснику простыми словами, как устроены позиционные системы счисления и как переводить числа из одной системы в другую.


## Файлы справочника

- `glossary.md` — 10 основных терминов с определениями.
- `examples.md` — 4 разобранных примера с исходными данными, ходом решения и проверкой.
- `questions.md` — 3 вопроса с ответами
- `sources.md` — источники, по которым составлен справочник, и для чего использован каждый.

## Порядок использования
1. Изучение терминов. Использовать `glossary.md`.

3. Самостоятельная отработка материала. Использовать `questions.md`.
